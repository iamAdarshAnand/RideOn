# Contributing to RIDEON

Thank you for your interest in this Flutter and Node.js ride-hailing prototype.

## Getting started
1. Fork the repository and create a focused feature branch.
2. Follow the setup instructions in README.md.
3. Keep changes small and include a description of what you tested.
4. Open a pull request with screenshots for UI changes.

## Areas for contribution
- Flutter passenger and captain experiences
- Location-aware dispatch and trip lifecycle
- API validation, authentication, authorization and automated tests
- Accessibility, localization and documentation

## Security
Do not commit API keys, passwords, customer information, signing keys or database files. Report vulnerabilities privately to the repository maintainer rather than opening a public exploit issue.

## Scope
RIDEON is independent and not affiliated with Rapido, Ola or Uber. Do not reuse their protected logos or branding.
